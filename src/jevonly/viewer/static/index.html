A name on the left, the exact text to type on the right (e.g. destination → Shanghai PVG). When a field must be filled, Jev picks WHICH fact to use; it never invents a value. Leave empty if the goal needs no typing.
When no fact fits a text field, Jev spells the value from the goal one key per judgment (a-z, 0-9, space, backspace, ←/→ to move the caret, done), sees the field text with the caret marked as | and the site's suggestions as it types, and stops without pressing Enter so it can pick a suggestion on the next step.
Jev sees only what is on screen (controls and text), like a person would, and scrolling is an action it can choose. Smaller state per step, more steps on long pages.
Opens a real Chrome window on this machine instead of running headless. With the persistent profile this is the way past a bot check: solve it once by hand in that window, and later runs carry the cookies. Do not touch the window while a run is in progress.
With a check, the loop only stops when the CODE sees it; Jev's "done" is advisory. Without one, the loop stops on Jev's own signal, which measured 34/42 vs 42/42 in the report.
